# Homebrew tap for Garuda

[Garuda](https://madhu-sv.github.io/garuda/) is a terminal coding agent with an OS sandbox,
approvals and an audit log.

      brew tap madhu-sv/garuda
      brew trust --formula madhu-sv/garuda/garuda
      brew install garuda

The formula installs the npm package `@garuda-agent/garuda`. Source and issues:
https://github.com/madhu-sv/garuda
